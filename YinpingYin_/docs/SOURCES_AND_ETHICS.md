# Sources, access and ethics

See `datasets/catalog.csv` for all source URLs. Entries marked `candidate_recheck_before_use` require fresh checks of the source, downloadable file, columns, applicable license, human-subject consent, and derivative/redistribution restrictions. A publicly visible GitHub page is **not** permission to republish its datasets.

Avoid committing raw questionnaire response files, personally identifying participant data, scraped private posts, or restricted media. Secure access to datasets separately. Do not assume two datasets identify the same human participant. Place authorized local data under `data/raw/`, which is git-ignored.

Representative reviewed repository descriptions: CPED (https://github.com/scutcyr/CPED), ETC (https://github.com/UEC-InabaLab/ETCDataset), PELD (https://github.com/preke/PELD), RECCON (https://github.com/declare-lab/RECCON), MELD (https://github.com/declare-lab/MELD).
