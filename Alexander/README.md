# Alexander's Research

The reusable language model, paper-derived loss helpers, tests, and experiment
outputs have moved to [small_language_model](../small_language_model/README.md)
at the repository root so all students can use them.

Use `python -m small_language_model.train` from the repository root. The old
`Alexander.small_language_model` import path is no longer supported. Historical
reports and source snapshots retain their original contents and paths as records
of the experiments that produced them.
